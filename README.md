# Deep_Reinforcement_Learning

Deep Reinforcement Learning coursework repository with a project layout for
modeling, training, and experimentation.

## Directory structure

```text
.
├── checkpoints/        # Saved training checkpoints
├── configs/            # Experiment and model configuration files
├── data/
│   ├── processed/      # Processed datasets/features
│   └── raw/            # Original datasets
├── experiments/        # Experiment outputs and tracking artifacts
├── logs/               # Training/evaluation logs
├── models/             # Exported/best model artifacts
├── notebooks/          # Exploratory and analysis notebooks
├── scripts/            # Utility scripts (train, evaluate, preprocess)
├── src/
│   ├── agents/         # RL agent implementations
│   ├── environments/   # Environment wrappers and custom environments
│   ├── evaluation/     # Evaluation logic and metrics
│   └── training/       # Training loops and orchestration
└── tests/              # Test suite
```
